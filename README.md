### EU Countries Overview - Data Warehouse (SQL/SSIS + Power BI)

**Problem:**
How to transform the public datasets about European countries into a single analytical model that supports meaningful comparative analysis across economics, crime, politics, and culture?

**Outcome:**
A time-aware data warehouse backed by a galaxy schema and SSIS ETL pipelines, enabling Power BI reports to combine country-level indicators over time accurately.

➡️ **Repository:** *(link to repo)*

### CryptoStock Predictions - Big Data Lambda Architecture (Python + Apache Big Data)

**Problem:**
How can real-time financial market data be ingested, processed at scale, and served to an analytics dashboard with price predictions?

**Outcome:**
An end-to-end Lambda Architecture platform combining Kafka/NiFi streaming with Spark batch pipelines and HBase-backed OHLC aggregates, surfaced through a live Shiny dashboard.

➡️ **Repository:** [CryptoStockPrediction](https://github.com/szuvarska/CryptoStockPrediction)
